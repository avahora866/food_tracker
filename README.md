# Food Tracker

A personal app that logs what I eat each day with a good-enough calorie and protein estimate. Nothing else.

## Layout

```
lib/
  main.dart                 app + theme
  providers.dart            Riverpod providers (db, day, recipes, ingredients)
  data/
    nutrition.dart          units, slots, kcal/protein maths, 3am day rollover, amount parsing
    database.dart           drift tables + queries (snapshot rule lives here)
    database.g.dart         generated by drift — do not edit
  screens/
    today_screen.dart       home: one page per day, four slots
    add_meal_sheet.dart     searchable picker, quick add, new meal
    edit_entry_screen.dart  edit one day's copy of a meal
    meals_screen.dart       recipe library
    recipe_editor_screen.dart
    ingredients_screen.dart ingredient manager / picker
```

## Commands

```bash
flutter run
```

```bash
flutter test
```

After changing tables in `lib/data/database.dart`, regenerate and bump `schemaVersion` with a migration:

```bash
dart run build_runner build
```
